# JobSystem

JobSystem is a PHP and MySQL job portal for local XAMPP setups. Employers can post jobs and jobseekers can browse and apply for them.

## Installation

1. Place the project folder inside `xampp/htdocs`.
2. Start Apache and MySQL in XAMPP.
3. Set up the database connection in `config/database.php`.
4. Open `http://localhost/JobSystem` in your browser.
